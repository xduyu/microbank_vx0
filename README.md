# micro-bank-cpp 🏦

A pocket-sized console banking application built with C++. This project serves as a practical sandbox for mastering core Object-Oriented Programming (OOP) concepts, pointer management, and modern CMake build configurations.

## Features
* **User Authentication:** Simulates user login by matching credentials against an internal database.
* **Balance Retrieval:** Securely fetches and displays the current account balance for authenticated sessions.
* **Clean Architecture:** Demonstrates explicit separation of concerns across multiple source (`.cpp`) and header (`.h`) files.

## Project Structure
* `includes/` - Header files defining class interfaces and internal models.
* `src/` - Implementation files for application logic.
* `CMakeLists.txt` - Build automation setup.
